Positional Encoding & Transformer Context Flow

How modern LLMs combine token identity with sequence position and contextual attention.

1. Token Embedding (E)

Static dictionary lookup mapping token ID → ℝ384. "Bank" always has the exact same initial raw embedding vector.

2. Positional Encoding (P)

Adds sequential order information: Xi = E(wi) + P(i). Prevents "dog bites man" from equating to "man bites dog".

3. Self-Attention Disambiguation

Multi-head attention rotates the token vector: "river bank" clusters near water/nature, while "money bank" shifts towards finance!

Why Dimensionality Reduction?

Bridging the gap between 384-dimensional machine models and human 3D perception.

1. The High-D Dilemma

The embedding model represents each concept as a point in 384-dimensional hyperspace. Human beings cannot visualize spaces higher than 3 dimensions directly.

2. Mathematical PCA Projection

Principal Component Analysis calculates the orthogonal eigenvectors of the Gram matrix ($B B^T = U \Lambda U^T$), finding the exact 3 axes containing maximum data variance.

3. Preserving Semantic Proximity

Original 384-D vectors remain unchanged for all similarity math. PCA coordinates are used strictly for spatial rendering, preserving semantic clustering.

The new entry is joined with the existing $N$ vocabulary vectors into an $(N+1) imes 384$ matrix.

Step 3: Recompute PCA

Jacobi spectral diagonalization determines the new global eigenvectors and 3D projected coordinates.

Existing points interpolate to their new positions while the new point arrives with a glowing beacon!

01

What is Vocabulary & Tokenization?

Computers cannot read letters or words natively; they operate strictly on numerical values. Vocabulary represents the finite dictionary of known symbols an AI model has learned. Tokenization is the algorithmic process of chopping raw text strings into discrete atomic elements called Tokens.

Input: "unbelievable"
Tokens: ['un', '##believ', '##able'] (Subword WordPiece tokenization)
Token IDs: [4895, 29014, 3085] (Lookup integers)
02

What is an Embedding? (Sparse vs Dense)

Historically, text was encoded using One-Hot Vectors: arrays of thousands of zeros with a single 1. However, one-hot encodings are completely orthogonal: the vector for "apple" is just as distant from "mango" as it is from "airplane". An Embedding is a continuous, dense numerical array where each dimension captures an abstract latent semantic feature. Words with similar meanings share similar coordinate values!

03

Why 384 Dimensions?

Human language contains nuanced hierarchies: fruit vs vehicle, past vs present, formal vs casual, edible vs inanimate. A single number cannot capture this richness. The all-MiniLM-L6-v2 model uses 384 dimensions. Larger models like BERT or GPT use 768 to 4096 dimensions. Each dimension represents a learned semantic axis in high-dimensional hyperspace.

04

Cosine Similarity & Geometric Angles

In high-dimensional space, the absolute length of a vector can vary due to frequency. Therefore, we measure semantic likeness by calculating the cosine of the angle ($ heta$) between two vectors:

$$\text{Cosine Similarity}(\mathbf{A}, \mathbf{B}) = \frac{\mathbf{A} \cdot \mathbf{B}}{\|\mathbf{A}\| \|\mathbf{B}\|} = \cos(\theta)$$

$\text{Score} = 1.0$ indicates identical direction (e.g., King & King); $\text{Score} \approx 0.7\text{–}0.9$ indicates strong semantic relationship (e.g., King & Queen); $\text{Score} \le 0.1$ indicates unrelated concepts (e.g., King & Apple).

05

Exact Jacobi PCA Dimensionality Reduction

How do we transform 384 dimensions into 3 dimensions ($x, y, z$) for Three.js rendering without losing semantic clustering? We implement Principal Component Analysis (PCA) natively in JavaScript via the Jacobi Spectral Method:

  1. Mean-Center: Subtract column means $\mu$ from the $N \times 384$ embedding matrix $X$ to form centered matrix $B$.
  2. Gram Matrix: Compute the symmetric $N \times N$ inner-product matrix $K = B B^T$.
  3. Jacobi Diagonalization: Iteratively apply Givens rotations to annihilate off-diagonal elements until convergence, extracting eigenvalues $\lambda_i$ and eigenvectors $v_i$.
  4. Coordinate Projection: Project each word vector onto the top 3 eigenvectors: $\text{Coord}_k = \sqrt{\lambda_k} \cdot v_k$.
